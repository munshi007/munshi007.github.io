About

I build production AI systems: multi-agent workflows, RAG with traceable citations, and the data pipelines underneath them. I've been shipping data infrastructure since 2019, from ETL at Tata Consultancy Services to LLM platforms at Berlin startups.

I care most about the part demos skip: evaluation, grounding and safety. That's why I built Aura-State, which proves an agent is injection-safe before it ships.

Aura-State

A design-time verifier for LLM agents: point it at a LangGraph, CrewAI, AutoGen or MCP agent and it proves the agent can't be tricked into leaking data, or shows the exact path that can.

  • Checks five properties: taint safety, output obligations, liveness, calibration and abstention
  • Parses agent source without executing it, and fails CI on regressions
